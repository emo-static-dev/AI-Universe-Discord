# AI Universe Discord Bot

🌌 The world's biggest AI-focused Discord community with advanced automation, moderation, and AI features.

## Features

- Server Builder System (50+ categories, 500+ channels, 250+ roles)
- AI Chatbot & Assistant
- Professional Role Hierarchy
- Moderation System (anti-spam, anti-raid, warnings, bans)
- Leveling & Economy System
- Ticket System
- Community Tools (welcome, verification, giveaways)
- Dashboard API

## Tech Stack

- Node.js, TypeScript, Discord.js v14
- PostgreSQL + Prisma ORM
- Redis Caching
- Express.js API
- Docker Support
- GitHub Actions CI/CD

## Getting Started

1. Clone and install: `npm install`
2. Configure: `cp .env.example .env`
3. Setup database: `npm run prisma:migrate`
4. Start: `npm run dev`
